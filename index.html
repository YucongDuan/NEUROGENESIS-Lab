Run the full laboratory.

Download and extract the release, open a terminal in its project folder and use Python 3.10 or later. No API key or package installation is required.

Open http://127.0.0.1:8766 after starting the server.

Read the complete quick start →
python run.py list
python run.py run hh --out runs/my-hh
python run.py replay runs/my-hh
python run.py serve --port 8766
